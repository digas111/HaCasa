# Update HaCasa

Updating HaCasa is handled by HACS.

1. Open HACS.
2. Open the HaCasa repository page.
3. Choose **Update** when an update is available.
4. Restart Home Assistant after HACS finishes the update.

If you made local edits inside `www/community/HaCasa`, back them up before updating. HACS owns that folder and can replace files during an update.
